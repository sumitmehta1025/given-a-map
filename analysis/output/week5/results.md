## 6. Graph blind spots (plan §7)

- The reference fixes change **49** functions or classes that the graph has a node for. **4** of them have **no edges** (nothing calls them and they call nothing, as far as the graph knows).
- In **6** of 26 tasks, no changed line could be matched to a graph node (e.g. the fix adds new code, or changes lines outside any function or class).
- So blind spots don't explain the null result: the graph covers almost every fix, but the agent rarely asks it.
